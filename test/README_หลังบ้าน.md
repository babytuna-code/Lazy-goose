# ระบบหลังบ้านเก็บคะแนน — แบบทดสอบรวมบท

ใช้วัดประสิทธิภาพของสื่อ: ดูว่านักเรียนที่เล่นเกมท้ายบทแล้ว สามารถทำแบบทดสอบรวมบทได้หรือไม่

## ลำดับการใช้งานของนักเรียน

`test.html` → "เริ่มทำแบบทดสอบ" → `student.html` (กรอก username) → `quiz1` – `quiz10` → `testscore.html`

- ระบบ **สุ่มโจทย์ 10 ข้อจากคลัง 50 ข้อ** ให้ตอนกรอก username โดยสัดส่วนบท อัตราส่วน : สัดส่วน : ร้อยละ = **3 : 3 : 4**
  และสลับบทที่ได้ 4 ข้อวนไปทุกครั้งที่ทำ (ร้อยละ → อัตราส่วน → สัดส่วน)
- คลังโจทย์อยู่ใน `question-sets.js` (5 ชุด × 10 ข้อ) แต่ละข้อมีรหัส เช่น `s2q5` = ชุดที่ 2 ข้อ 5 และระบุบทไว้ใน `chapter`
- เมื่อถึงหน้า `testscore.html` ระบบบันทึกคะแนน 1 ครั้งต่อการสอบ 1 รอบ (รีเฟรชหน้าก็ไม่บันทึกซ้ำ)

### ข้อมูลที่เก็บ

วันที่-เวลา, **username**, คะแนน, ร้อยละ, **คะแนนรายบทของแบบทดสอบ**,
**คะแนนเกมท้ายบทล่าสุดของแต่ละบท** (อัตราส่วน / สัดส่วน / ร้อยละ — ขึ้นว่า "ยังไม่เล่น" ถ้ายังไม่เคยเล่นในเครื่องนั้น),
ถูก/ผิดรายข้อ, รหัสโจทย์ที่ได้ และคำตอบที่เลือกรายข้อ

> คะแนนเกมท้ายบทอ่านจากเครื่องที่นักเรียนใช้สอบ จึงแม่นยำเมื่อนักเรียนเล่นเกมและทำแบบทดสอบบนเครื่องเดียวกัน (เช่น มือถือของตัวเอง)

## ตั้งค่า Google Sheets (แบบที่ 2 — รวมคะแนนจากทุกเครื่อง)

ทำครั้งเดียว ใช้เวลาประมาณ 5–10 นาที

1. สร้าง Google Sheets ใหม่ 1 ไฟล์ (เช่น ตั้งชื่อ "คะแนน Lazy Goose")
2. เมนู **ส่วนขยาย → Apps Script**
3. ลบโค้ดเดิม แล้ววางโค้ดทั้งหมดจาก `google-apps-script/Code.gs` → กดบันทึก
4. กด **ทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่ (New deployment)**
   - ประเภท: **เว็บแอป (Web app)**
   - เรียกใช้ในฐานะ (Execute as): **ฉัน (Me)**
   - ผู้ที่มีสิทธิ์เข้าถึง (Who has access): **ทุกคน (Anyone)**
5. กดอนุญาตสิทธิ์ (ถ้าขึ้นคำเตือน ให้กด Advanced → Go to ... (unsafe) เพราะเป็นสคริปต์ของเราเอง)
6. คัดลอก **Web app URL** ที่ลงท้ายด้วย `/exec`
7. เปิด `test/score-config.js` แล้ววางลิงก์:

   ```js
   googleSheetUrl: "https://script.google.com/macros/s/xxxxxxxx/exec",
   googleSheetViewUrl: "https://docs.google.com/spreadsheets/d/xxxxxxxx/edit",   // ไม่บังคับ
   ```

8. **ทดสอบ 1 รอบ:** ทำแบบทดสอบจนจบ หน้าคะแนนต้องขึ้น "✓ ส่งคะแนนให้ครูเรียบร้อยแล้ว"
   แล้วใน Google Sheets ต้องมีชีตใหม่ชื่อ "คะแนนแบบทดสอบรวมบท" พร้อมแถวข้อมูล
9. ดาวน์โหลดเป็น Excel ได้จาก Google Sheets: **ไฟล์ → ดาวน์โหลด → Microsoft Excel (.xlsx)**

> - นักเรียนต้องเปิดสื่อผ่านอินเทอร์เน็ต (เช่น อัปโหลดโฟลเดอร์ `lazy1` ขึ้น GitHub Pages / Netlify แล้วส่งลิงก์ให้นักเรียน)
> - ถ้าตอนสอบเสร็จไม่มีอินเทอร์เน็ต คะแนนจะถูกเก็บในเครื่องก่อน และระบบจะส่งให้อีกครั้งเมื่อนักเรียนเปิดหน้ากรอกชื่อครั้งถัดไป
> - ถ้าแก้โค้ดใน Apps Script ต้อง Deploy ใหม่: Manage deployments → Edit → Version: New version

## หน้าหลังบ้านครู (`test/admin.html`)

- **เป็นลิงก์แยก ไม่มีลิงก์ในหน้าของนักเรียน** — ครูเปิดจาก URL โดยตรง เช่น `https://<เว็บของคุณ>/test/admin.html`
- รหัสผ่านเริ่มต้น `1234` ต้องตั้งให้ตรงกัน 2 ที่: `adminPin` ใน `score-config.js` และ `ADMIN_PIN` ใน `Code.gs`
- เมื่อตั้งค่า Google Sheets แล้ว หน้านี้จะ **ดึงคะแนนของนักเรียนทุกเครื่องจาก Google Sheets** มาแสดง
  (ตาราง สถิติ และปุ่มดาวน์โหลด Excel) กด "โหลดข้อมูลล่าสุด" เพื่ออัปเดต
- ถ้ายังไม่ได้ตั้งค่า จะแสดงเฉพาะคะแนนที่เก็บในเครื่องที่เปิดอยู่
- ไฟล์ Excel มี 3 ชีต: สรุปคะแนน, คำตอบที่เลือก (พร้อมรหัสโจทย์), วิเคราะห์รายข้อ-รายบท

## ไฟล์ที่เกี่ยวข้อง

| ไฟล์ | หน้าที่ |
|---|---|
| `score-config.js` | **ไฟล์ตั้งค่า** — ลิงก์ Google Sheets และรหัสผ่านหน้าหลังบ้าน |
| `question-sets.js` | คลังข้อสอบ 5 ชุด ชุดละ 10 ข้อ |
| `quiz-render.js` | สร้างหน้าโจทย์ตามชุดที่นักเรียนได้รับ |
| `answer-key.js` | เฉลยพร้อมวิธีทำรายข้อ 5 ชุด (แสดงในหน้า `testanswer.html` ผ่านปุ่ม "ดูเฉลย" ในหน้าคะแนน) |
| `quiz.js` | ตรวจคำตอบและบันทึกผลรายข้อ |
| `student.html / .css / .js` | หน้ากรอก username ผู้สอบ |
| `scorebook.js` | บันทึกคะแนน, ส่ง Google Sheets, สร้างไฟล์ Excel |
| `admin.html / .css / .js` | หน้าหลังบ้านสำหรับครู |
| `google-apps-script/Code.gs` | โค้ดสำหรับวางใน Google Apps Script |

## หมายเหตุด้านความปลอดภัย

รหัสผ่านหน้าหลังบ้านใช้กันนักเรียนเปิดเล่นเท่านั้น เพราะโค้ดทั้งหมดอยู่ฝั่งเบราว์เซอร์
ข้อมูลบน Google Sheets ปลอดภัยตามสิทธิ์การแชร์ไฟล์ของครู (ไม่ต้องแชร์ไฟล์ให้นักเรียน)
